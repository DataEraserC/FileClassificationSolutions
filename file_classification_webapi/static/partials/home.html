文件分类系统说明

📘 系统概述

文件分类系统是一个用于管理和组织文件、组、标签及其关联关系的系统。通过该系统，用户可以：

  • 管理文件信息
  • 创建和管理组层次结构
  • 为文件和组添加标签
  • 建立组之间的关系
  • 通过多种条件查询和筛选数据

📂 数据结构

文件 (Files)

  • ID: 文件唯一标识符
  • 类型: 文件类型（如 txt, pdf, doc 等）
  • 路径: 文件存储路径
  • 引用计数: 文件被引用的次数
  • 组ID: 文件所属组的ID

组 (Groups)

  • ID: 组唯一标识符
  • 名称: 组名称
  • 描述: 组描述信息
  • 引用计数: 组被引用的次数
  • 父组ID: 父组的ID（用于构建组层次结构）

标签 (Tags)

  • ID: 标签唯一标识符
  • 名称: 标签名称
  • 描述: 标签描述信息
  • 引用计数: 标签被引用的次数

文件组关联 (File Groups)

  • 文件ID: 文件的ID
  • 组ID: 组的ID

组标签关联 (Group Tags)

  • 组ID: 组的ID
  • 标签ID: 标签的ID

组关系 (Group Relations)

  • 第一个组ID: 第一个组的ID
  • 第二个组ID: 第二个组的ID
  • 关系类型: 组关系的类型

⚙️ 系统功能

基本操作

  • 新增: 在各个模块中添加新的记录
  • 修改: 编辑现有记录的信息
  • 删除: 删除不需要的记录（支持单个和批量删除）
  • 查询: 通过简单搜索或复杂条件搜索查找记录

搜索功能

  • 简单搜索: 在每个模块的顶部提供基于常用字段的搜索框
  • 复杂查询: 支持构建复杂的查询条件，可以组合多个条件进行精确查询

分页功能

所有模块的数据展示都支持分页，可以：

  • 选择每页显示的记录数量（10/20/50/100）
  • 跳转到指定页面
  • 查看总记录数和总页数

🧭 使用说明

  1. 使用左侧导航栏切换不同的功能模块
  2. 在每个模块中，可以使用顶部的搜索框进行简单查询
  3. 点击"复杂查询"按钮可以打开高级查询界面
  4. 使用"新增"按钮可以添加新的记录
  5. 表格中的操作列提供了针对单条记录的编辑和删除功能
  6. 使用表格顶部的复选框可以选择多条记录进行批量操作
